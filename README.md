## Which pattern? (read the problem and look for the signal)

| Signal in the problem | Pattern | Where |
|---|---|---|
| "seen before?", "how many times", "pair that sums to X" | Map / Set | Easy §2 · Medium §2 |
| **Sorted** array, palindrome, pairs/triplets | Two pointers | Easy §3 · Medium §3 |
| **Contiguous** subarray / substring, "longest/shortest" | Sliding window | Easy §4 · Medium §4 |
| "sum of a range", "subarray with sum K" | Prefix sum (+ Map) | Easy §5 · Medium §2 |
| Sorted + "find", or "the minimum that still works" | Binary search | Easy §6 · Medium §6 |
| Parentheses, "next greater", undo | Stack | Easy §7 · Medium §5 |
| `head`, `.next` | Linked list (dummy, slow/fast) | Easy §8 · Medium §13 |
| `root`, `.left/.right` | Tree recursion, level-order BFS | Easy §9 · Medium §14 |
| Intervals `[start, end]` | Sort by start and merge | Medium §7 |
| Grid of `"1"`/`"0"`, islands, neighbours | DFS/BFS on a matrix | Medium §8 |
| Dependencies, "prerequisites" | Graph + topological sort | Medium §9 |
| "all combinations / subsets / permutations" | Backtracking | Medium §10 |
| "the K largest / most frequent" | Heap or sort | Medium §11 |
| "how many ways", "fewest coins", "max without adjacent" | Dynamic programming | Medium §12 |

## The size of n tells you the complexity they expect

| n up to | Complexity that passes |
|---|---|
| 20 | O(2ⁿ): backtracking |
| 1,000 | O(n²): two nested `for` loops |
| 100,000 | O(n log n): sort, heap, binary search |
| 10⁸ | O(n): one `for`, Map, window |
